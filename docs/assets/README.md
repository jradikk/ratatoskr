# README images

The root README expects these files in this directory. Generate them without any
text in the image; titles and labels live in the README itself.

| `ratatoskr-hero.png` | 1500×500 (3:1) | Banner at the top of the README |

## Prompts

### ratatoskr-logo.png

Flat vector logo mark: a stylized red squirrel silhouette curled into a circle,
its bushy tail forming a loop that looks like a tunnel or arrow, inside a
circular badge. Bold simple shapes, 2–3 colors only (warm orange-red squirrel,
deep navy background, teal accent line through the tail suggesting a data
path). Geometric, symmetrical, works at 32px. No text, no gradients, white
background.

### ratatoskr-hero.png

Wide cinematic banner illustration, modern flat vector style with subtle Nordic
knotwork details. A nimble red squirrel (Ratatoskr from Norse mythology) racing
up the trunk of a giant stylized world tree whose branches are glowing network
cables. Many small glowing data packets stream from the tree's lower roots
(dozens of small houses/containers) and converge into two or three sturdy
glowing lanterns in the branches; from each lantern a single strong teal beam
leaves toward distant city skylines on the horizon. The squirrel carries one
packet between the roots and a lantern. Deep navy night background, teal and
violet glow, warm orange accents on the squirrel. Clean, minimal, generous
negative space left and right, tech-product aesthetic. No text, no letters, no
logos.

### ratatoskr-sidecar-vs-gateway.png

Split-screen isometric comparison illustration, flat vector, white background.
Left half, slightly muted and cluttered: a row of many small blue container
blocks, each with its own tiny padlocked tunnel pipe sticking out and running
separately to the sky, pipes tangled and crossing, a few pipes broken with
small red warning sparks. Right half, clean and orderly: the same number of
small blue container blocks sending thin teal light streams that converge into
two sturdy teal gateway towers with shield emblems; from each tower exactly one
thick armored tunnel goes to the sky. A thin dashed teal arc links the two
towers, suggesting failover. Palette navy, teal, violet, one red accent on the
left side only. Soft shadows, lots of whitespace. No text, no labels, no
letters, no numbers.

### ratatoskr-how-it-works.png

Isometric technical illustration of a Kubernetes cluster drawn as a clean
platform of blue hexagonal blocks. Many small application containers are spread
across the platform; tagged containers emit bright teal particle streams that
converge into a cluster of two gateway towers with shield emblems standing in
one corner of the platform. Each tower sends one thick armored teal tunnel off
the platform toward a distant globe; the two tunnels end at two different
highlighted cities, suggesting two different providers. Untagged containers
send plain grey lines only to other blocks inside the cluster. One extra tower
in the background is dimmed with a small red barrier in front of it, and its
former streams are visibly rerouting to the healthy towers. Flat isometric
style, soft shadows, white background, palette navy, teal, violet, one red
accent. No text, no labels, no letters.

### ratatoskr-social.png

Minimal dark tech poster, 2:1. On the left third, a geometric low-poly red
squirrel in profile, leaping, holding a glowing teal data packet. On the right,
an abstract stylized world tree made of thin glowing network lines whose many
small branch tips funnel into a few bright nodes. Navy-to-black gradient
background, faint Norse rune-like geometric patterns, teal and violet neon
accents. Leave a clean empty horizontal band in the middle for a title overlay.
No text, no letters.

Tip: generate the logo first and use it as a style reference for the others.
